# Roadmap

Цель: музыкант кидает трек и получает то, что раньше снимал на слух: темп, размер, тональность, аккорды по тактам и ноты отдельно для каждого инструмента. Кроме того, звук можно описывать математикой и тут же слышать и видеть результат.

## v0.1 — MVP (готово)

- `sfunc analyze`: темп, размер (3/4 или 4/4), тональность, аккорды по тактам, JSON.
- `sfunc roll`: piano-roll в PNG с полосой аккордов и сеткой тактов, экспорт в MIDI.
- `sfunc synth`: звук из формулы. Безопасный разбор AST, осцилляторы, `phase()` для FM, `seq`, `adsr`, фильтры, эхо, патчи `.sfx`, параметры `-p`, график `--plot`.
- Тесты на синтетике с известным ответом, включая круг «формула → звук → анализ».

## v0.2 — Инструменты по отдельности и визуализатор (почти готово)

- [x] `sfunc stems song.mp3` — разделение на 6 дорожек моделью **Demucs `htdemucs_6s`**, опциональная зависимость `[stems]`, кеш по хешу файла.
- [x] `--stem bass|piano|…` для `analyze`, `--stems` для `roll` и `view`: ноты ищутся в каждой дорожке, пустые дорожки пропускаются.
- [x] Удары барабанов (бочка, малый, хэт) по дорожке ударных; в MIDI на 10-м канале.
- [x] Уверенность для каждой ноты и тепловая шкала цвета («тепловизор»): синий — сомнительно, белый — уверенно.
- [x] **`sfunc view` — окно-визуализатор** в стиле визуализаторов FL Studio: ноты едут к линии воспроизведения и вспыхивают, клавиатура подсвечивается, аккорды, ударные, мини-карта, звук синхронно.
- [x] Piano-roll прямо в терминале; PNG с панелью на каждый инструмент; `--open` для картинок и звука.
- [ ] Транскрипция нот бэкендом **basic-pitch** (Spotify, ONNX): больше найденных нот, особенно в быстрых партиях, и настоящая вероятность модели вместо эвристической уверенности.
- [ ] CI в GitHub Actions: тесты на Windows, Linux и macOS.

## v0.3 — Синтез из формул 2.0 (основная фича)

- [ ] `--play`: проиграть результат прямо из терминала (sounddevice). Сейчас `--open` открывает WAV во внешнем плеере.
- [ ] `sfunc synth --watch patch.sfx`: перерисовка и перепроигрывание при сохранении файла (live coding).
- [ ] Стерео: `left = ...`, `right = ...`, функция `pan(x, p)`.
- [ ] **Инструменты из формул по MIDI**: `sfunc synth bell.sfx --midi melody.mid`. Каждая нота рендерится формулой, где `f`, `vel`, `t`, `gate` относятся к этой ноте. Вместе с v0.2 это позволяет снять мелодию с трека и переиграть её своим звуком.
- [ ] Пользовательские функции в патчах: `osc(f) = saw(phase(f)) + 0.5*square(phase(f/2))`.
- [ ] Новая DSP-обработка: фильтр с модулируемой частотой среза и резонансом, `env(точки...)`, `reverb`, `distort`, `delay` с модуляцией (chorus и flanger).
- [ ] Библиотека патчей (бас, лиды, ударные, пэды) и `sfunc synth --list`.
- [ ] Экспорт в flac и mp3.

## v0.4 — Точнее ритм и гармония

- [ ] Нейросетевой трекер долей и сильных долей (**beat_this** или madmom) вместо эвристики. Это даст 6/8, 12/8, 5/4 и 7/8, кривую темпа для живых записей и определение свинга.
- [ ] Расширенный словарь аккордов: 7, maj7, m7, sus2/4, dim, aug, обращения (`C/E`) по басовой хроме.
- [ ] Тональность по участкам (модуляции) и функциональный анализ римскими цифрами (I–V–vi–IV).
- [ ] Структура песни (вступление, куплет, припев) по матрице самоподобия: `sfunc analyze --sections`.
- [ ] Подсказка каподастра и транспонирование аккордов: `--transpose -2`.
- [ ] Уверенность для темпа и аккордов, как сейчас у нот.

## v0.5 — Визуализация для музыкантов

- [ ] В визуализаторе — соло и приглушение звука отдельных инструментов (дорожки Demucs уже есть).
- [ ] Экспорт визуализатора в видео (MP4) для соцсетей.
- [ ] **Табулатура для гитары**: раскладка нот по струнам и ладам с минимальным смещением руки (динамическое программирование).
- [ ] Экспорт в MusicXML (music21), чтобы открыть ноты в MuseScore.

## v0.6 — Качество и распространение

- [ ] Метрики точности через mir_eval на открытых датасетах: GTZAN и Ballroom (темп и доли), Isophonics и Billboard (аккорды), MAESTRO (фортепиано), GuitarSet (гитара). Метрики проверяются в CI, чтобы ловить регрессии.
- [ ] Кеш результатов анализа, параллельная обработка, длинные треки.
- [ ] Публикация на PyPI: `pipx install soundfunc`.
