# sound_func — `sfunc`

CLI для музыкантов: разбирает трек вместо снятия на слух и синтезирует звук из математических формул.

- **Анализ:** темп (BPM), размер такта, тональность, аккорды по тактам.
- **Piano-roll:** ноты в PNG с полосой аккордов и сеткой тактов, экспорт в MIDI для DAW.
- **Синтез из формул:** `sin(2*pi*440*t) * exp(-3*t)` → WAV. Есть осцилляторы, огибающие, фильтры, FM, секвенсор.

> Статус: ранний MVP. Разделение на дорожки (барабаны / пианино / гитара) и нейросетевая транскрипция описаны в [ROADMAP.md](ROADMAP.md).

## Установка

Нужны Python 3.10+ и [uv](https://docs.astral.sh/uv/) (или pip). Для mp3/m4a нужен ffmpeg в `PATH`.

```bash
git clone https://github.com/DoshiCkk/sound_func.git
cd sound_func
uv sync            # или: pip install -e .
uv run sfunc --help
```

## Анализ трека

```bash
sfunc analyze song.mp3
sfunc analyze song.mp3 --start 30 --duration 20   # только фрагмент
sfunc analyze song.mp3 --json > song.json
```


## Piano-roll и MIDI

```bash
sfunc roll song.wav -o song.png --midi song.mid
```

На картинке ноты по высоте (C4, C5... на оси), сильные доли обозначены жирными линиями, сверху идёт полоса аккордов. MIDI-файл открывается в любой DAW. Сейчас транскрипция работает без нейросети: на чистых записях результат приличный, на плотном миксе много лишних нот.

## Синтез звука из формул

```bash
sfunc synth "sin(2*pi*440*t) * exp(-3*t)" -d 2 -o beep.wav
sfunc synth "sin(phase(220 + 30*sin(2*pi*5*t)))" -o vibrato.wav --plot vibrato.png
sfunc synth -f examples/patches/bell.sfx -p f=330 -d 4 -o bell.wav
sfunc functions        # справочник функций
```

Формула — выражение от времени `t` в секундах. В файле `.sfx` можно писать несколько строк с переменными и комментариями. Результатом считается последнее выражение или переменная `out`:

```python
# examples/patches/arp.sfx — арпеджио Am–C–G–F
step = 0.125
root = seq(2, 57, 60, 55, 53)
f = midi(root + seq(step, 0, 7, 12, 15, 12, 7))
gate = exp(-14 * (t % step))
lowpass(saw(phase(f)), 1800) * gate
```

| Группа | Функции |
|---|---|
| Математика | `sin cos tan tanh exp log sqrt abs sign floor min max clip where`, операторы `+ - * / ** % //`, сравнения `t < 1` (дают 0/1) |
| Осцилляторы | `saw(x)`, `square(x, duty)`, `tri(x)`, `noise()`; принимают фазу в радианах, как `sin` |
| Частота | `phase(f)` — интеграл частоты: корректные FM, вибрато и глиссандо; `note("A4")`, `midi(69)` |
| Время | `seq(step, v1, v2, ...)` — пошаговый секвенсор; `adsr(a, d, s, r)` — огибающая |
| Обработка | `lowpass(x, fc)`, `highpass(x, fc)`, `echo(x, delay, feedback)` |
| Переменные | `t`, `n` (сэмпл), `sr`, `T` (длительность), `pi`, `tau`, `e`, свои через `-p name=value` |

Формулы не передаются в `eval`. Разрешены только числа, арифметика, сравнения и функции из списка выше, поэтому чужой `.sfx` безопасно запускать.

Готовые патчи лежат в [examples/patches](examples/patches): `kick`, `bell`, `arp`, `pad`.

## Как это работает

| Задача | Метод |
|---|---|
| Темп и доли | `librosa.beat.beat_track` по onset-огибающей мел-спектра |
| Размер такта | акцент на каждой доле (удар в низах + onset + смена гармонии); выбирается группировка по 3 или по 4, в которой первая доля выделяется сильнее |
| Тональность | Крумхансл–Шмуклер: корреляция хромы с профилями 24 тональностей |
| Аккорды | шаблоны мажорных и минорных трезвучий по хроме гармонической части, сглаживание Витерби, привязка к долям |
| Ноты | CQT с разрешением 1/3 полутона, пики по высоте, подавление обертонов |

## Разработка

```bash
uv sync --extra dev
uv run pytest
```

Тесты анализа проверяют темп, размер, тональность и аккорды на синтетических треках с заранее известным ответом (`tests/conftest.py`). Аудиофайлы в репозиторий не кладём.
